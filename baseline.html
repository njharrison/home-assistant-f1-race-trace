Reference vs selected driver — GPS speed by lap position

Speed is expressed as % of lap per second because the circuit coordinates are not calibrated to metres. In driver-specific mode, the reference belongs to the selected driver; every car retains the same common reference lap duration. The driver line uses raw GPS-derived centreline progress between consecutive observations (no extra smoothing). Select a driver and replay lap to compare speed at the same physical track positions.

Each coloured line represents the driver's estimated reference-relative progress. GPS samples can be projected using a trajectory-normal intersection or the original nearest-segment method; lap boundaries are unwrapped when crossing the provisional S/F marker. Abrupt jumps indicate GPS/centreline projection ambiguity or a provisional S/F calibration issue, not real gains. Race-only mode excludes pre-race movement and aligns each driver’s first racing-lap completion to a physical S/F crossing. Timing and GPS streams may still differ by a few seconds. The 106.5-second default is estimated from observed GPS progress, not official lap timing. Use the learned profile to reduce circuit-wide braking and acceleration waves, or switch to constant speed for comparison. Export the normalised profile as JSON to reuse at Suzuka with a different reference lap duration. A car matching the chosen reference pace should have a roughly horizontal trace; this remains a diagnostic, not a validated race-gap chart.
